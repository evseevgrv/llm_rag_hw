# Как устроен проект

Основной код находится в корне репозитория. build_index.py создает поисковые
фрагменты и векторы E5. retrieval.py объединяет BM25 и dense-поиск, выбирает
контекст и добавляет соседние блоки. predict.py отправляет один запрос Qwen,
проверяет структуру ответа и записывает trace. Общие функции находятся в common.py.

## Вспомогательные файлы

В support находятся:

- pdf_extract.py и prepare_data.py для извлечения учебника и подготовки JSONL.
- own_tasks.py с авторскими вопросами и эталонами.
- download_models.py для скачивания закрепленных ревизий моделей.
- serve_qwen.py и generation.py для запуска Qwen на GPU.
- evaluate.py для расчета метрик по правилам задания.
- run_experiments.py для сравнения пяти режимов.
- make_report.py и report_base.md для сборки отчета.
- run_colab.ipynb для запуска в Colab.
- tfkp_15_qa.md с исходным открытым набором.

## Настройки

Параметры поиска находятся в config.json. chunk_tokens и chunk_overlap задают
размер окон. retrieval_k управляет глубиной поиска, context_seeds числом основных
блоков, neighbor_radius соседством, context_tokens бюджетом контекста.
После изменения окон, корпуса или E5 нужно пересобрать индекс.

Параметры генерации и квантизации находятся в runtime.json. После изменения
настроек GPU-сервера его нужно перезапустить. В экспериментах параметры
генерации должны оставаться одинаковыми.

Инструкции модели находятся в SYSTEM и NO_CONTEXT в predict.py.
Математические обоснования проверяются вручную, автоматический оценщик
сравнивает варианты, цитаты и формат.

## Данные и результаты

Локальные файлы хранятся в workspace. Эта папка исключена из Git.
В workspace/data находятся корпус, открытые вопросы и эталоны,
в workspace/models веса, в workspace/index индекс,
в workspace/artifacts результаты отдельных режимов и журнал endpoint.

В корень копируются ответы и trace режима final. Все команды запуска приведены
в README.md. report.md содержит проверенный разбор текущего прогона.
Повторный запуск make_report.py заменяет его автоматически собранной версией.
