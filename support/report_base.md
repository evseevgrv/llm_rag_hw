# Доказательный RAG по ТФКП

## Данные

Используется учебник Горяйнова и Половинкина 2025 года, все 147 страниц PDF.
Текст извлекается с восстановлением кириллицы, дробей, степеней и сопряжения
по шрифтам и координатам символов. Сложные формулы могут передаваться неточно.
Вызовов LLM при подготовке корпуса нет.

Исходные блоки содержат абзацы с формулами и номера страниц. Для поиска они
делятся на окна до 400 токенов E5 с перекрытием 48. Цитаты указывают исходные
block_id. Эталоны не включаются в индекс. Дополнительно составлены восемь
вопросов, по два на категорию, которые не использовались для настройки поиска.

## Поиск и ответ

BM25 использует k1=1.5 и b=0.75. Служебные слова, отдельные числа и большинство
одиночных переменных исключаются из лексического представления. Русским словам
от шести букв добавляется пятибуквенный префикс. Команды TeX нормализуются.

Dense-поиск использует multilingual-E5-small на CPU, усреднение токенов с маской,
L2-нормировку и cosine similarity. Для запросов и фрагментов применяются
префиксы query: и passage:. Ревизия модели зафиксирована в config.json.

Две выдачи top-20 объединяются по RRF(d)=Σ 1/(60+rank(d)). Отбираются шесть
разных блоков и их соседи из того же раздела. Повторы удаляются. Контекст
ограничен 4200 токенами Qwen, отдельный фрагмент 900 токенами. При превышении
общего бюджета последние фрагменты исключаются.

Qwen3.5-4B делает один вызов на вопрос с выключенным thinking. Параметры
генерации одинаковы во всех режимах. Ответ содержит варианты, короткое
обоснование и не более четырех цитат. Если данных или найденных доказательств
недостаточно, модель должна объяснить отказ. Технические ошибки получают ноль.

Расход берется из endpoint usage и сверяется с журналом сервера. Для обычных
вопросов s=A(0.8+0.2F), для недостаточности данных балл дается за правильный отказ.
Q усредняет результаты четырех категорий. Стоимость C=mean(input+4·output+256·calls),
эффективность E=min(1,C_ref/max(C,1)). При превышении лимитов или неизвестном
расходе эффективность обнуляется.

## Внешний код и помощь ИИ

Использованы PyMuPDF, rank-bm25, NumPy, PyTorch, Transformers, Hugging Face Hub
и HTTPX. GPU-сервер использует Accelerate, bitsandbytes, FastAPI и Uvicorn.
Codex помог с планом, реализацией, вопросами и текстом отчета.
